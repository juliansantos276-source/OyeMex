# Oye Mex — Escucha la literatura mexicana

Audiolibros en español mexicano de obras clásicas de **dominio público**. Presiona play y deja que el cuento te lleve.

## Contenido
- `index.html` — sitio de una página (jugador de audio + atribución)
- `audio/elzarco_cap1.mp3` — *El Zarco — Principio* (≈28 min)

## Libro
**El Zarco**, de *Ignacio Manuel Altamirano* (1834–1893). Publicado póstumamente (~1900).
Obra de dominio público en México y Estados Unidos. Texto tomado de la Biblioteca Digital ILCE (México); se preserva la redacción original.

## Voz
Narración generada por voz de texto-a-voz (es-MX-Jorge, edge-tts). Audiolibro de producción propia; no afiliado al autor ni a la fuente.

## Identidad visual
El hero utiliza `assets/mexico-map.svg`, un mapa en blanco de México descargado de Wikimedia Commons para uso como elemento editorial de fondo. Se mantiene local para que el diseño no dependa de un recurso externo en cada visita.

## Deploy
Sitio estático — arrastra esta carpeta a Netlify Drop, o conecta este repositorio a Netlify. El dominio `oyelomex.com` se apunta al sitio publicado.
